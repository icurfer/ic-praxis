# ic-praxis 개선 제안 — msa-fe(원조) 다중 세션 운영 사례

- 작성일: 2026-07-11
- 근거: ic-praxis 를 추출해 낸 원조 저장소 `msa-fe`(FE 1 + BE 18 모노레포군 허브)를 **여러 Claude 세션으로 동시 운영**하며 발견한 공백.
- 대상 버전: `main` (2026-07-11 시점)

praxis 5축(Constitution / 4단 문서 / 게이트 / 메모리 / verify 스킬)은 **단일 세션**의 규율은 잘 잡는다. 그러나 실제로 여러 BE 를 병렬로 굴리려고 **세션을 여럿 띄우자** 5축이 다루지 않는 실패가 났다. 아래는 우선순위 순 (왜 문제 → 근거 → 제안).

---

## P0. 다중 세션/서브에이전트 조율 규율이 없다

### 문제

praxis 5축 어디에도 "**여러 세션·에이전트가 동시에 일할 때**"의 규율이 없다. 허브 저장소(모든 세션이 문서·버전을 여기로 모으는 곳)를 여러 세션이 공유하면, git 이 못 잡는 **조용한 디스크 덮어쓰기**가 난다.

### 근거

msa-fe 에서 독립 CLI 세션 2개(각각 다른 BE 작업)가 **같은 작업 트리**에서 `version`·`CHANGELOG.md`·`docs/requirements/backlog.md` 를 동시 편집했다. 두 세션이 서로의 존재를 몰라(핸드오프 채널 없음) **마지막 저장이 조용히 이겼다**(2026-07-11, nvlog↔ssh). BE 레포는 형제 디렉토리라 격리됐지만, **허브 하나로 수렴**하는 구조라 거기서 전부 충돌했다. `git pull --rebase` 도 다른 세션의 미스테이징 WIP 때문에 실패한다.

### 제안

1. **CLAUDE.md 템플릿에 "Multi-session rule" 스타터 절 추가**:
   - 독립 세션 여러 개 대신 **메인 1 + 서브에이전트** — 서브의 최종 메시지가 메인으로 자동 반환 = 핸드오프 채널.
   - **서브 = 자기 하위 레포만**(코드 + 그 레포 버전 트리거). **허브(docs/공용 파일)는 메인만 쓴다.**
   - 하나의 하위 단위 = 하나의 세션.
   - 큰 병렬 편집이 꼭 필요하면 `isolation: worktree`. **lock 파일은 지양**(증상만 가림 — 근본은 작업 트리 공유이므로 격리로 푼다).
2. 이유(why)를 규칙에 박는다 — praxis 철학대로 "실제 사고에서 값을 치른" 규칙으로.

## P1. `settings.json` 훅 축과 서브에이전트 축이 문서엔 있는데 스캐폴드엔 없다

### 문제

README 의 "Rule Routing Decision Tree" 는 `.claude/settings.json` 훅(PreToolUse/PostToolUse)을 명시적 층으로 든다. 그러나 `templates/` 에 **예시 settings.json 이 없다.** 서브에이전트(`.claude/agents/`) 축은 **문서에도 스캐폴드에도 아예 없다** — P0 을 기계로 강제할 자리가 비어 있다.

### 근거

msa-fe 에서 P0 규율을 강제하려면 두 파일이 필요했는데 praxis 에 원본이 없어 새로 설계해야 했다:
- `.claude/agents/be-worker.md` — 단일 하위 레포 전용 서브. "허브 미수정 + 끝나면 핸드오프 요약 반환" 규율을 **에이전트 정의 자체에 내장** → 사람 기억에 의존 안 함.
- `.claude/settings.json` — `git push` 전 다중세션 리마인더(비차단, always exit 0 검증). tool-use 시점 강제 층의 최소 실체.

### 제안

1. `templates/.claude/settings.json` 추가 — **안전한 비차단 훅 1개** 예시(항상 exit 0; exit 2 는 차단이므로 스타터에선 지양). 라우팅 트리가 가리키는 층에 실제 착지점을 준다.
2. `templates/.claude/agents/` 축 도입 — "하위 작업 전용 서브(상위/허브 미수정 + 핸드오프 반환)" 예시 1개. README 5축을 **6축("Sub-agent delegation")** 으로 확장하거나, 최소한 라우팅 트리에 한 줄 추가.
3. `praxis-review.sh` 성장 통계에 `skills`/`agents` 개수 + 게이트 주석 스타일 로케일 대응(msa-fe 는 `# ── 규칙 N` 한글 주석) — 카운팅이 프로젝트 로케일에 안 깨지게.
